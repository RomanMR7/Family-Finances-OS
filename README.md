# Family Finances OS (v0.2.0-release)
### Закрытая автономная операционная система управления семейными финансами

> **100% Offline-First • Zero-Cloud • Двойная бухгалтерская запись • Сквозное шифрование AES-256-GCM • Бессерверная P2P-синхронизация по локальной сети**

---

## 1. О системе

**Family Finances OS** — это защищенная домашняя финансовая система, созданная для полного контроля над семейным капиталом без передачи каких-либо данных сторонним облачным сервисам, банкам или зарубежным серверам.

### Ключевые архитектурные принципы:
1. **Полная автономность (Zero-Cloud):** Приложение работает исключительно на ваших домашних устройствах. В коде нет внешних API, метрик, трекеров и облачных баз данных. Ваши финансы никогда не покидают периметр вашего дома.
2. **Абсолютная математическая строгость:** Бухгалтерский учет построен на канонической **двойной записи** ($\sum \text{Дебет} \equiv \sum \text{Кредит}$) с целочисленной арифметикой в копейках (`INTEGER cents`). Ошибки округления и нестыковки баланса исключены на уровне архитектуры.
3. **Единый семейный бюджет:** Финансы семьи — это общий неделимый капитал. Карты мужа и жены объединены в общий ликвидный пул.
4. **Контейнерное шифрование (Envelope Encryption):** На диске хранится только зашифрованный бинарный контейнер `family_finances.db.enc`. В открытом виде база разворачивается только в оперативной памяти компьютера (`:memory:`) после ввода мастер-пароля. При блокировке или закрытии приложения ключ немедленно стирается из памяти (Zero-Fill).
5. **Бессерверная P2P-синхронизация (LAN):** Ноутбуки и смартфоны супругов обмениваются данными напрямую по домашнему Wi-Fi через защищенный протокол с взаимной аутентификацией HMAC-SHA256 и гибридными логическими часами (HLC).

## 2. Быстрый запуск в 1 клик (Windows)

### Вариант 1: Запуск на основном компьютере / ноутбуке
Дважды щелкните по файлу:
```text
start.bat
```
* Скрипт сам найдет установленный Python (3.10+), запустит локальный сервер и автоматически откроет веб-интерфейс в браузере по адресу:  
  **`http://127.0.0.1:8000`**

### Вариант 2: Запуск с доступом для смартфонов семьи по домашнему Wi-Fi
Дважды щелкните по файлу:
```text
start_lan.bat
```
* Сервер запустится с сетевой привязкой ко всем адаптерам (`0.0.0.0`) и отобразит в консоли адрес для подключения со смартфона, например:  
  **`http://192.168.1.45:8000`**
* Супруг/супруга могут просто навести камеру телефона на QR-код на экране монитора (кнопка «📱 Подключить телефон» в шапке) и мгновенно войти в систему без ввода IP-адресов.

### Вариант 3: Запуск в Docker контейнере (Фоновый режим 24/7)
Если на вашем компьютере запущен Docker:
Дважды щелкните по файлу:
```text
start_docker.bat
```
(или выполните команду в консоли: `docker compose up -d --build`)
* Сборка минимального контейнера на базе `python:3.12-slim` с непривилегированным пользователем `appuser` (UID 10001).
* Порты `8000:8000` (Web UI/API/PWA) и `41234:41234/udp` (P2P Discovery Beacon) автоматически проброшены.
* База данных и ключи сохраняются на хост-машине в `./family_finances_os/data` (данные переживают любые перезапуски и обновления контейнера).
* Встроенный Healthcheck контролирует статус сервера каждые 30 секунд.

## 3. Первый запуск и настройка (Холодный старт с нуля)

1. При первом открытии система автоматически определит отсутствие базы данных и покажет экран **«Первичная настройка: Создание Владельца семьи»**.
2. Введите:
   - **Имя пользователя** (по умолчанию `admin`);
   - **Отображаемое имя** (например, `Папа` или `Глава семьи`);
   - **Мастер-пароль** (не менее 6 символов, рекомендуется надежная кодовая фраза).
3. Нажмите **«Инициализировать защищенную семью»**.
4. Система создаст шифрованный контейнер, сгенерирует криптографический ключ `DEK`, настроит базовый план счетов и иерархическое дерево из 26 категорий расходов и доходов.

### Мастер быстрого ввода начальных балансов (Zero-State Onboarding)
После входа в систему на вкладке **«Обзор»** появляется интерактивный пошаговый мастер настройки бюджета:
- **Карта Мужа (1011):** ввод начального остатка на карте;
- **Карта Жены (1012):** ввод начального остатка на карте;
- **Семейные наличные (1020):** сумма наличных в кошельках и домашнем сейфе;
- **Кредитная карта (2020):** текущий долг по кредитке и кредитный лимит;
- **Обязательный регулярный платеж месяца:** название, сумма и день оплаты (например, «Ипотека / аренда», «ЖКХ»).

Нажмите кнопку **«Сохранить и начать вести бюджет»**. Система автоматически выполнит корректные бухгалтерские проводки через единый счёт капитала `3010`, сразу же пересчитает показатель **Safe-to-Spend** и скроет баннер онбординга.

## 4. Универсальный импорт банковских выписок (CSV, TSV, JSON)

На вкладке **«Импорт выписок»** доступна загрузка операций из любых российских банков (Сбербанк, Т-Банк / Тинькофф, Альфа-Банк, ВТБ и др.):
1. **Файловый импорт или прямая вставка текста:** можно перетащить файл выписки или скопировать строки прямо из буфера обмена.
2. **Умная очистка сумм:** движок автоматически распознает форматы `1 234,50 ₽`, `-450.00`, `(500,00)` и знаки валют.
3. **Эвристическое автоопределение категорий:** система автоматически подбирает категории по ключевым словам («Пятерочка», «Перекресток» → Продукты; «Аптека 36.6» → Аптека и здоровье; «Яндекс Заправки» → Транспорт).
4. **Гарантия от повторного импорта (Идемпотентность):** каждая строка выписки получает детерминированный криптографический хэш `idempotency_key = sha256(...)`. Случайная повторная загрузка того же файла не приведет к задвоению транзакций.

## 5. Финансовая аналитика и предиктивный прогноз ликвидности (Cash Flow)

На вкладке **«📈 Аналитика и прогноз»** семья получает инструменты для глубокого контроля бюджета:
1. **4 Ключевых KPI семьи:**
   - **Доходы за период:** сумма всех зарплат и поступлений;
   - **Расходы за период:** все подтвержденные траты;
   - **Норма сбережений (Savings Rate):** процент сохраняемых средств (норма $\ge 15–20\%$, отрицательное значение сигнализирует о жизни в дефицит);
   - **Финансовая автономность (Cash Runway):** сколько дней семья может прожить при текущем темпе трат без новых доходов.
2. **Интерактивная круговая диаграмма (SVG Donut Chart):**
   - Наглядная разбивка трат по категориям (без сторонних внешних библиотек, чистый офлайн-SVG).
   - Распределение трат по членам семьи (Муж, Жена, Общие расходы).
   - Топ-5 крупнейших покупок за выбранный период.
3. **Моделирование Cash Flow на 30, 60 и 90 дней:**
   - Стартует с чистой ликвидной позиции ($\text{Карты + Наличные} - \text{Долг по кредиткам}$).
   - Ежедневно моделирует списание обязательных платежей по календарю и оценку повседневных трат (Burn Rate).
   - Защита от двойного учета: уже оплаченные в текущем месяце обязательства не списываются повторно.
   - **Предиктивное предупреждение о кассовом разрыве:** система заранее сообщает точную дату, сумму дефицита и конкретную статью расхода, которая вызовет нехватку денег.

## 6. Концепция единого капитала и показатель Safe-to-Spend

Главный экран системы рассчитывает показатель **Safe-to-Spend (Безопасно к тратам)** — это реальная сумма свободных денег, которую семья может потратить сегодня без риска сорвать обязательные платежи:

$$\text{Общая ликвидность} = \sum \text{Дебетовые карты мужа и жены} + \sum \text{Наличные} + \sum \text{Расчетные счета}$$

$$\text{Обязательства к оплате} = \sum \text{Неоплаченные регулярные платежи месяца (Аренда, Кредиты, Детсад, ЖКХ)}$$

$$\text{Safe-to-Spend} = \max(0, \text{Общая ликвидность} - \text{Долг по кредиткам} - \text{Обязательства к оплате})$$

### Индикация кассового разрыва (Дефицита):
* **Зеленый индикатор (Профицит):** Семья в безопасности, текущих свободных средств достаточно для покрытия всех обязательств месяца.
* **Красный индикатор (Кассовый разрыв):** Если обязательства превышают доступные деньги, Safe-to-Spend блокируется на **`0.00 ₽`**, а на экране появляется предупреждение с точной суммой дефицита.

## 7. Модель безопасности (Envelope Encryption)

Хранение данных организовано по стандарту конвертного шифрования:
1. **KEK (Key Encryption Key):** Производный ключ, вычисляемый из мастер-пароля через `PBKDF2-HMAC-SHA256` с **600 000 итерациями** и случайной 16-байтной солью. Вычисляется только один раз при разблокировке (~300 мс).
2. **DEK (Data Encryption Key):** Случайный 256-битный симметричный ключ базы данных, защищенный KEK через шифр `AES-256-GCM`.
3. **Мгновенное сохранение (< 2 мс):** При добавлении транзакций база шифруется ключом DEK напрямую через аппаратные инструкции процессора AES-NI без повторного вычисления PBKDF2.
4. **Атомарная запись и теневая копия (`.db.enc.bak`):** Запись нового состояния ведется во временный файл с вызовом `fsync()`, предыдущая валидная копия сохраняется как `.db.enc.bak`, после чего выполняется атомарная замена файла. Потерять базу невозможно даже при внезапном отключении электричества.
5. **Защита оперативной памяти:** По нажатию кнопки **«Запереть»** (или при выходе) буфер DEK в памяти перезаписывается нулями (`wipe_memory`), активная сессия уничтожается, а любые попытки чтения блокируются с кодом `423 Locked`.

## 8. Локальная P2P-синхронизация без облака

Система позволяет супругам вести учет параллельно на разных устройствах в офлайне:
* **Автопоиск (Discovery Beacon):** Устройства рассылают UDP-пакеты на порт `41234` в домашней сети Wi-Fi, автоматически находя друг друга.
* **Гибридные логические часы (HLC):** Отслеживают причинно-следственные связи транзакций независимо от расхождения системного времени на телефонах.
* **Журнал изменений (CDC Event-Log):** Изменения реплицируются атомарно со всеми проводками.
* **Бесконфликтность:** Бухгалтерские проводки коммутативны — при слиянии изменений балансы сходятся до копейки на обоих устройствах.
* **Защита от чужих устройств в Wi-Fi:** Все пакеты обмена заверяются криптографической подписью `HMAC-SHA256`.

## 9. Мобильный PWA и быстрое QR-сопряжение устройств

Система оптимизирована для использования со смартфонов (iPhone и Android) как полноценное нативное мобильное приложение:
1. **PWA (Progressive Web App):**
   - Включает файл манифеста `/manifest.json`, Service Worker `/sw.js` для мгновенной загрузки оболочки и адаптивные мета-теги с поддержкой Safe-Area («челки» и выреза iPhone).
   - При открытии в Safari (iOS) нажмите кнопку «Поделиться» → **«На экран 'Домой'»**. Приложение установится на домашний экран с фирменной иконкой и будет запускаться в полноэкранном автономном режиме без адресной строки.
   - В Chrome / Chromium (Android и ПК) появляется кнопка **«📥 Установить»** для добавления на рабочий стол в 1 клик.
2. **Мгновенное подключение смартфона по QR-коду (100% Offline):**
   - Нажмите в шапке приложения кнопку **«📱 Подключить телефон»**.
   - На экране монитора откроется окно с векторным QR-кодом, сгенерированным на чистом Python без каких-либо внешних сервисов (Zero CDN).
   - Супруг/супруга наводит камеру смартфона на экран — система мгновенно выполняет защищенное одноразовое сопряжение и входит в общий семейный бюджет без ручного ввода IP-адресов и паролей.
